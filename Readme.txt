Requirements

->Python 3.10 or later
->MySQL Server
->pip

Installation

->Clone the repository:
git clone https://github.com/navanee1407/Attendance-Tracker.git


->Install dependencies:
cd Attendance-Tracker
python -m pip install -r requirements.txt

->Configure your MySQL credentials using environment variables if required by the application. For Windows PowerShell:
$env:ATTENDANCE_DB_PASSWORD = "your_mysql_password"
